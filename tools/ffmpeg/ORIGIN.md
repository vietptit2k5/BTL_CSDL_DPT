# FFmpeg local tools

Copied for this local project from the existing Gyan FFmpeg9.0.2 full build installed on the user's computer by WinGet. Files are not downloaded or modified. `ffmpeg -version` and `ffprobe -version` are recorded in the stage1 validation artifact. The full distribution is available at https://www.gyan.dev/ffmpeg/builds/ and FFmpeg licensing information at https://ffmpeg.org/legal.html. These binary files are ignored by Git.
